# Redesign pass — 2026-10-11 (overnight)

Applied the "DailyPlanner Redesign" design canvas to the app, plus the bugs
and security gaps found along the way. Every commit went to `main` after the
full test suite passed (592 → 619 tests, 0 failures). The branch
`redesign/plus-jakarta` points at the same commits as a backup.

## 1. Run this SQL in Supabase

All five files are safe to re-run. The app works before you run them — new
columns are stripped and retried, history writes are skipped — you just
don't get the new data until they're in.

| Order | File | What it adds |
|---|---|---|
| 1 | `MIGRATION_KR_CHECKINS.sql` | `key_results.last_checked_at` (backfilled from `created_at`) and the `kr_checkins` history table, for the weekly check-in |
| 2 | `MIGRATION_PROJECT_COLOR.sql` | `projects.color` with a hex-only CHECK, for the colour picked when creating a project |
| 3 | `MIGRATION_TASK_COMPLETED_AT.sql` | `project_tasks.completed_at`, kept by a trigger whenever a task becomes done / un-done, for the sprint burndown |
| 5 | `MIGRATION_PREP_THOUGHTS.sql` | `prep_thoughts`: your Random thoughts questions and their answers |
| 4 | `MIGRATION_PREP_PROGRESS.sql` | `prep_progress`: rehearsed ticks, mock-interview scores and system-design quiz scores for the Interview Prep hub, synced across devices |

## 2. What changed

**Look (all pages, through the design tokens)**
- Ink & Lime palette: near-black primary with a white label, lime in dark
  mode with an ink label; indigo for links, the active nav and focus.
  Neutral stone ground. All contrast pairs still pass
  `tests/test_palette_contrast.py` in both themes.
- Plus Jakarta Sans everywhere (also for numbers, with tabular figures).
- Softer radii, bold tight headings, PWA theme colours.
- ~30 hard-coded old blues became tokens. 123 white-on-primary labels now
  use `--color-on-primary`, so nothing is white-on-lime in dark mode.
- Priorities quote banner is a flat ink card. The 404 and 500 pages are
  redesigned (with dark mode and useful actions).

**New**
- `/goals/check-in` — weekly check-in for hand-kept key results. A
  "Weekly check-in" button on Goals, and each key result shows "updated N
  days ago", flagged after a week.
- Project colour on the new-project form, the project cards and the
  Roadmap.
- Menu links to Day timeline, Settings and Pending sync, which had no way
  in.

**Fixed**
- Dark mode: Priorities quadrant titles and the Inbox heading were
  near-black on near-black (this predates the redesign).
- Checklist history streak read 0 all day until the last tick. An
  unfinished today no longer counts as a miss.
- Health score gave 10 free points (a constant weight score).
- The top bar's avatar sat 14px off-screen. The Quick Bucket text box
  overflowed on phones. A grey band showed down the left edge on phones
  (the closed menu's shadow).
- A raw "+" and a row of plain links appeared under pages that load
  `pt-shared.js` without its CSS.
- `/untimed/schedule` upsert used the wrong conflict key, so it always
  failed.
- Ticking a matrix task never synced its linked project task (a
  `get(single=True)` TypeError).

**Security**
- 27 write endpoints acted on a row id without checking the owner. Any
  signed-in user could edit or delete another user's project tasks,
  matrix tasks, subtasks, habit order or Roadmap dates. All are now
  scoped to the caller (`tests/test_ownership.py`). The vault, money,
  chat and family features were already correct.

## 3. Second pass (same night)

- **Read-side security audit**: all 495 reachable reads checked. Fixed:
  - reading another user's task text via send-to-matrix;
  - other users' key-result titles on the day board;
  - tasks linked to someone else's project, goal, KR, initiative, epic or
    sprint, now refused on create and update;
  - family-task titles in search for non-family accounts;
  - the people picker listing everyone;
  - admin access falling back to the whole family (set `ADMIN_EMAILS`);
  - chat attachments without a room;
  - cross-user duplicate checks;
  - a constant-time cron-secret check.
- **Dead code removed**: `load_todo`, `save_todo`, `get_goal_for_date`,
  `services/reminder_service.py`.
- **Share to DailyPlanner** confirm page, saving to Inbox, TravelReads or
  References.
- **Sprint burndown** over the sprint's own dates.
- **Reminders prompt**: says what is sent, and "Not now" is remembered for
  14 days.
- **Today**: first-run steps for a new account; loading skeleton on the
  home list.
- **Speed**: the font is now self-hosted. The first commit had made every
  page wait on Google Fonts, so first paint went from ~0.93 s to ~1.35 s
  on a phone connection; it is back to ~0.9 s.

## 4. Interview Prep hub (afternoon)

- **One menu item.** Interview Prep and TPM Case Rounds are merged into one
  page with four tabs, each on its own path: Overview, Case rounds
  (`/interview-prep/cases`), Behavioral, System design. `/tpm-rounds`
  redirects, keeping `?topic=`.
- **Less clutter.** The page drew both banks in full on load (3,000+
  buttons, a 29,000px scroll). Banks now load when their tab opens, 40
  cards at a time; syllabus, stories and the practice log fold away.
  The links on the old TPM page that dropped you at the top of Interview
  Prep now open the right tab.
- **Progress on the server.** Rehearsed / practised ticks for the case
  rounds, behavioral and system design banks are saved in `prep_progress`,
  keyed by title, so they sync across devices and survive bank edits.
  Old device-only ticks are copied up once.
- **Readiness** now counts case rounds (20%, weighted P0 > P1 > P2) and
  the two banks (10%), alongside syllabus, stories and consistency.
  "Do these next" lists the top unrehearsed cases.
- **Ranking fix.** Priority is now a statement, not a percentile: every
  must-rehearse case is P0, "very common / asked in most loops" is P1.
  "Work with a PM when you disagree" no longer ranks last.
- **Case rounds:** notes, Plan (schedule to a day) and Share on every case;
  a phone-readable PDF; and a **mock interview** mode (timer, one follow-up
  probe, self-score; a 3 or 4 counts as rehearsed).
- **12 new cases**: peak-sale readiness, platform migration, the one-page
  CEO status, a 30% budget cut, killing a program, the annual OKR cycle,
  shipping an LLM feature, a slipping vendor, and a new Engineering
  Leadership round (tech debt, reliability, an underperforming manager,
  the hiring bar). 34 cases in all.
- **Fixed:** `ai_sde_progress` upserts had no conflict target, so the
  second save of any topic failed with 409.

## 5. System design deep dives (evening)

- **70 deep dives** in the System design tab: all 55 prompts from the Beyz
  system design question bank plus 15 classics (web crawler, Dynamo-style
  KV store, Snowflake IDs, payments, stock exchange, ticket booking,
  leaderboard, ad-click aggregation, Kafka, S3, Google Maps, distributed
  cache, email, online judge, flash sale). **Uber is the flagship**: ~26k
  words, 17 concepts, 70 quiz questions.
- Each design: overview and a "say this out loud" cheat sheet; the Beyz
  Clarify -> Design -> Defend walkthrough with a spoken opener; BRD; PRD
  with back-of-the-envelope capacity maths; HLD with an ASCII architecture
  diagram and critical flows; LLD with APIs, data model, classes,
  algorithms (pseudocode) and a sequence diagram; edge cases; tech stack
  with alternatives; every distributed-systems concept taught from first
  principles with interview Q&A; trade-offs; failure modes and metrics;
  interviewer follow-ups; a choose-the-best-answer quiz; references.
- **Concepts view**: every concept across all designs (consistent hashing,
  quorum, saga, backpressure...), each linking into the designs that use it.
- **Quiz**: full run, 10 random, or retry the ones missed; keyboard A-D and
  Enter. A full run's best score is saved; 80%+ marks the design studied.
- Each design has its own link (`/interview-prep/design/uber`), a PDF, notes
  and a Plan button. The original 128-entry bank is still there as
  "Quick reference".
- Content lives in `sd_deep/*.json`; `python3 sd_deep_bank.py --check`
  validates every file against `sd_deep/SCHEMA.md`.

## 6. Random thoughts (night)

- New Interview Prep tab: write any question that comes to mind and the app
  writes a detailed answer in a fixed teaching format - short answer,
  intuition, how it works, worked example, misconceptions, how to say it in
  an interview, key takeaways, and self-check questions (tap to reveal).
- Answers are written in the background (Claude if ANTHROPIC_API_KEY is
  set, else Gemini, else Groq Llama 3.3 70B) and the page updates itself.
- Explain simpler / Go deeper / your own follow-ups stay threaded; mark
  "understood", pin, rewrite, edit, PDF, delete; search and filters.
- First question shipped and added automatically: how an e-commerce site
  stops the last units being sold to two people at peak load.
